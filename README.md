# Лабораторная работа №4 — Вариант 17

**Функции-генераторы и работа со встроенными функциями Python**

## Описание

Приложение демонстрирует использование функций-генераторов и встроенных функций Python
(`map`, `filter`, `zip`, сортировка по ключу, `isinstance`) на трёх задачах варианта 17.
Включает графический интерфейс на PySide6, тесты pytest и параллельную версию
генератора с замером производительности.

## Задания варианта 17

### Задание 1. Сочетания из трёх цифр
Строка `d = "0123456789"`. Генератор формирует все сочетания из трёх цифр
и выдаёт их как **целые числа** (не строки). Выводятся первые 50 значений.

**Результат:** `0 1 2 3 … 49` (1000 комбинаций всего)

### Задание 2. Значения функции f(x) на отрезке
Функция-генератор возвращает значения `f(x)` для `x ∈ [a; b]` с шагом `0.01`.
Параметры `a`, `b` и сама функция `f` задаются как аргументы генератора.
**Без использования коллекций.**

**Вызов:** `a = -20`, `b = 100`, `f(x) = -1.5x + 2` (лямбда-функция прямо в аргументе).

**Результат (первые 20):** `32.0 31.985 31.97 … 31.715`

### Задание 3. Сортировка словаря по убыванию ключей
Функция `get_sort(d)` сортирует словарь по убыванию ключей (лексикографически)
и возвращает список значений.

**Пример:**
```python
d = {'cat': 'kom', 'horse': 'лошадь', 'tree': 'дерево',
     'dog': 'собака', 'book': 'книга'}
get_sort(d)  # ['дерево', 'лошадь', 'собака', 'kom', 'книга']
```

## Инструкции по запуску
### 1. Установка зависимостей
pip install -r requirements.txt
###2. Запуск демонстрации в консоли
python app/generators.py
Выведет результаты всех трёх заданий.

### 3. Запуск GUI

python -m app.main
Откроется окно с тремя вкладками (по одной на задание).

### 4. Запуск тестов

Все быстрые тесты (17)
python -m pytest -v

Тесты производительности (Well-done, 2)
python -m pytest -m slow -v -s

Обработка исключений
Все функции валидируют входные данные и выбрасывают:

TypeError — неверный тип аргумента (например, digits=123, f не callable).

ValueError — некорректное значение (пустая строка, step <= 0, a > b, repeat <= 0 и т.д.).

GUI перехватывает все исключения и показывает пользователю диалоговое окно с сообщением.
